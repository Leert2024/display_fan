# 2026_RoboCon_R1_slave/keil_project
作者: 李睿彤

## 简介
这是下位机(STM32F407ZGT6)的工程文件。  
"下位机"是相对于作为主控的上位机(Linux)而言的。

## 部分配置说明
- 串口资源分配: USART1与上位机通信，USART2用于与控制小轮的大疆板通信
- CAN资源分配: CAN1用于与控制底盘电机、前腿电机、后腿电机的大疆板通信

## 命令使用说明
- `help`: 显示帮助
- `suckerctrl <which> <status>`: 控制吸盘
    - `<which>`: `0`或`1`，分别表示左侧和右侧吸盘
    - `<status>`: `0`或`1`，分别表示关闭和打开吸盘
- `armuserstarttask <id>`: 开始预设的机械臂任务
    - `<id>`: 任务ID，见下表

    |ID|任务|
    |:----:|:----|
    |`1`|左侧，举起至90°|
    |`3`|左侧，吸取地面的KFS（从上方）|
    |`5`|左侧，吸取20cm的KFS（从上方）|
    |`7`|左侧，吸取40cm的KFS（从上方）|
    |`9`|左侧，吸取60cm的KFS（从上方）|
    |`11`|左侧，回到初始位置|
    |`2`|右侧，举起至90°|
    |`4`|右侧，吸取地面的KFS（从上方）并举起至能放入九宫格底层的高度|
    |`6`|右侧，吸取20cm的KFS（从上方）|
    |`8`|右侧，吸取40cm的KFS（从上方）|
    |`10`|右侧，吸取60cm的KFS（从上方）|
    |`12`|右侧，回到初始位置|

- `armrightadjust <angle>`: 微调右侧机械臂角度
    - `<angle>`: 浮点数，大于0表示举高，小于0表示举低

对命令做开发的说明详见[README](Core\BUPT_RobotTeam_Libraries\SimpleLib\cmd\README.md)。

## 回显类型
除`help`命令返回的说明文本外，回显必以`[xxx] `的格式开头，结尾必为`\r\n`。
- `[OK] `: 执行成功
- `[ERROR] `: 错误，如执行失败(`[ERROR] fail\r\n`)、指令或参数非法(`[ERROR] invalid cmd\r\n`、`[ERROR] invalid param\r\n`)
- `[FATAL] `: 致命错误(如进入`HardFault_Handler`等)，此时下位机大概率不能再正常工作力(大悲)
- `[INFO] `: 状态告知信息(如告知初始化成功等)，通常可无视
- `[DEBUG] `: 调试信息(如显示当前状态等)，可无视
